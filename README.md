# 🤖 Ollama Agent

**Ollama Agent** — локальный персональный AI-ассистент для Telegram, построенный на Python, [Ollama](https://ollama.com/) и локальных LLM.

Проект предназначен для запуска собственного AI-агента **без облачных API и обязательной подписки на сторонние AI-сервисы**.

> 🚧 Проект находится в активной разработке.

---

## ✨ Возможности

### 💬 Общение с AI

Агент принимает обычные текстовые сообщения в Telegram и отправляет их локальной языковой модели через Ollama.

В качестве основной модели используется:

```text
qwen3:14b
```

---

### 👁️ Анализ изображений

Агент умеет принимать изображения из Telegram и передавать их Vision-модели.

Используемая модель:

```text
qwen3-vl:8b
```

Можно отправить:

* 🖼️ изображение без текста — агент самостоятельно попросит модель описать его;
* 📝 изображение с подписью — подпись используется как запрос к Vision-модели.

Например:

```text
[изображение]

Что находится на фотографии?
```

---

### 🧠 Локальный Brain

Вся логика взаимодействия с моделями вынесена в отдельный модуль:

```text
brain.py
```

Brain отвечает за:

* запуск Ollama;
* проверку доступности Ollama;
* управление моделями;
* автоматическую загрузку отсутствующих моделей;
* удаление ненужных моделей;
* выбор модели;
* отправку запросов;
* обработку изображений;
* системный prompt.

Telegram-часть при этом остаётся отдельно в:

```text
main.py
```

# 🚀 Установка

## 1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/Ollama-agent.git
cd Ollama-agent
```

---

## 2. Создание виртуального окружения

Windows:

```powershell
python -m venv venv
```

Активация:

```powershell
venv\Scripts\activate
```

После активации в терминале должно появиться:

```text
(venv)
```

---

## 3. Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

---

## 4. Установка Ollama

Ollama должна быть установлена на компьютере и доступна через команду:

```powershell
ollama --version
```

Проверить установленные модели:

```powershell
ollama list
```

Ollama API по умолчанию работает на:

```text
http://127.0.0.1:11434
```

# 🔐 Настройка

Открой:

```text
config.py
```

и укажи токен Telegram-бота:

```python
TELEGRAM_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
```

Также здесь находятся системный prompt и список необходимых моделей:

```python
MODELS = {
    "text": "qwen3:14b",
    "vision": "qwen3-vl:8b",
}
```

---

# 🧠 Управление моделями

Brain автоматически сравнивает установленные модели с моделями из `config.py`.

Например:

```python
MODELS = {
    "text": "qwen3:14b",
    "vision": "qwen3-vl:8b",
}
```

Если `qwen3:14b` отсутствует:

```text
Brain
 ↓
ollama pull qwen3:14b
 ↓
Модель установлена
```

Если установлена модель, которой нет в `MODELS`, Brain удалит её.

Например:

```text
ollama list

qwen3:14b
qwen3-vl:8b
phi4
```

При запуске:

```text
Удаление лишней модели: phi4
```

Таким образом, `MODELS` является источником истины для набора моделей проекта.

> ⚠️ Не добавляй в Ollama модели, которые хочешь сохранить отдельно от этого проекта: Brain будет считать их лишними.

# ▶️ Запуск

После настройки:

```powershell
python main.py
```

При успешном запуске в консоли появится примерно:

```text

[BRAIN] Запуск Ollama...
[BRAIN] Ollama успешно запущена.
[BRAIN] Проверка установленных моделей...
[BRAIN] Модель уже установлена: qwen3:14b
[BRAIN] Модель уже установлена: qwen3-vl:8b

[BRAIN] Brain готов к работе.

```

После этого можно открыть Telegram и отправить сообщение боту.

# 🖼️ Работа с изображениями

Изображение можно отправить двумя способами.

### Без подписи

```text
[🖼️ изображение]
```

Используется стандартный запрос:

```text
Опиши это изображение.
```

### С подписью

```text
[🖼️ изображение]

Что изображено на фотографии?
```

В этом случае именно подпись передаётся Vision-модели.

```python
TELEGRAM_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"

SYSTEM_PROMPT = """
Ты — личный AI-ассистент пользователя.

Отвечай полезно, точно и понятно.

Не выдумывай факты, если не уверен в ответе.
""".strip()

MODELS = {
    "text": "qwen3:14b",
    "vision": "qwen3-vl:8b",
}
```

# 🎯 Концепция

Главная идея проекта — создать собственного AI-ассистента, который не зависит от одного облачного сервиса.

```text
                 Ollama Agent
                      │
          ┌───────────┼───────────┐
          │           │           │
         Text       Vision       Code
          │           │           │
       Qwen3       Qwen3-VL     LLM
          │           │           │
          └───────────┼───────────┘
                      │
                    Brain
                      │
                   Telegram
```

В будущем Brain станет центральным уровнем, который будет самостоятельно определять, **какая модель и какой инструмент необходимы для выполнения запроса**.
